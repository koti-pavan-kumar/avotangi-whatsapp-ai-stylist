# Make.com Setup Instructions

## Prerequisites
- Make.com account (free tier)
- Twilio WhatsApp Business Sandbox
- Groq API key

## Quick Setup (15 minutes)

### Step 1: Import Blueprint
1. Log into Make.com
2. Create new scenario
3. Import `scenario-blueprint.json`
4. All modules will be pre-configured

### Step 2: Configure Credentials
1. Twilio connection:
   - Account SID
   - Auth Token
2. Groq API key in HTTP module:
   - Authorization header: `Bearer YOUR_KEY`

### Step 3: Update Twilio Webhook
1. Go to console.twilio.com
2. WhatsApp Sandbox settings
3. Update "When a message comes in" URL
4. Use your Make.com webhook URL

### Step 4: Activate
1. Toggle scenario ON
2. Schedule: Immediately
3. Test with WhatsApp message
